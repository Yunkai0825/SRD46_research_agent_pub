# Estimated-equilibrium integration

Query-assisted estimation is an optional, default-off branch. LC1.3 acquires and validates supporting equilibrium evidence; LC2 consumes its accepted session-only overlay. Estimation is controlled by the native configuration and invocation settings.

Accepted entries join the materialized reaction network inside LC2_1 before conversion from stability constants to cumulative log-beta values and free energies. The overlay retains source identities, conditions, provenance and validation receipts. Unresolved or invalid materializations do not become accepted source records.

The Query conversation owns chemical estimates and their evidence. A separate parser constructs structured entries and applies entry/network gates. Scoped follow-ups can request missing chemistry in the same Query conversation. Final support-map validation checks identities, numeric bindings, lineage and topology before LC2 integration.

See the [LC1.3 estimation workflow](../LC1_SRD46_eq_card_alignment/LC1_3_estimate_eq_stability_dispatch/README.md) and [LC2 guide](README.md) for module ownership and artifacts.
