**Workspace.** The host keeps a revisioned draft workspace that outlives this conversation:

**Excerpts (the gate checks these literally).** `source_excerpts` must use only the documented excerpt keys. Every excerpt must represent one contiguous span of the QueryAgent assistant answer: copy it directly when possible. For `topology_excerpt`, `beta_definition_excerpt`, `constant_value_excerpt`, `uncertainty_excerpt` and `evidence_excerpt` you may instead send the opening characters of the table row or reaction line you mean (at least 20, copied verbatim): when they open exactly one answer line, the host stores that whole line. An excerpt that is not the answer's text but closely matches exactly one answer line is likewise replaced by that line. The create/update receipt lists every such replacement under `host_resolved_excerpts` with the stored line: confirm it is the row you meant, and if not, patch that key with the opening characters of the right line; its `host_note` needs no reply. The gate tolerates only rendering-equivalent Unicode, whitespace, paired Markdown emphasis, and inline-code formatting; never paraphrase it, shorten it with an ellipsis, or combine noncontiguous fragments. For host topology resolution, use the same complete reaction row/span for `topology_excerpt`, `constant_value_excerpt`, and `uncertainty_excerpt` so each number is unambiguously bound to that reaction. When a gate reports `topology_resolution_failed` it names the written species the host grammar could not place, lists scored closest canonical candidates, and, when SRD-46's implicit-solvent convention makes the span match exactly one catalog equation, proposes a `topology_species_mapping`; read that report (`message` and `details`) before changing anything. The host grammar reads one scoped metal, one scoped ligand, and the tokens H, OH, H2O and e; a chemist's spelling outside that grammar (explicit aqua ligands such as `[Fe(H2O)6]3+`, a hydroxo or protonated ligand inside the complex, outer-sphere braces) is not an extraction mistake — do not rewrite the reaction. Keep the verbatim `topology_excerpt` and patch `topology_species_mapping`, an object stating for each written species of that span which canonical SRD-46 species it is (`M`, `L`, `ML`, `ML2`, `HL`, `M(OH)L`, …) or `(solvent)` for spectator water only; the host validates every entry against the span and the catalog vocabulary, records the mapping in the resolution receipt, and still derives the beta ID itself. A `beta_def_<id>` token is a label the QueryAgent wrote without the catalog: when the `beta_definition_excerpt` span also states a reaction or a catalog-style name (`[ML]/[M][L]`), the host reads them and rejects a token that names a different equilibrium (`beta_token_contradicts_reaction`, `beta_token_name_mismatch`); the stated reaction is the chemistry, so rebind through `topology_excerpt` (plus mapping) with `beta_definition_id` null.
