# Scoped source repair at LC2

A source fault is distinct from a Markdown/parser-format fault. The native compiler emits `SourceRepairRequired` for an equilibrium graph that cannot reach its free-component reference basis. Its diagnostic records exact unresolved equations, source IDs, input digest and selected pair. LC2_3's supervising reviewer may request source repair through `request_source_repair({"entry_keys":["<existing key>"],"reason":"<source defect>"})`. The controller derives the pair and archive IDs from the immutable card inventory; the tool accepts no replacement constants. Unfinished group reviews must be completed before unaffected decisions can be accepted.

An early LC2_1 source failure has no accepted deduplication baseline. The parent controller repairs the scoped LC1 selection and builds LC2 in a new attempt directory. A later source request retains its reviewed decisions as an `accepted_decision_overlay` with file hashes; `source_repair_pending` is not acceptance of the defective full card.

`repair_lc2_from_delta` is the late-repair bridge. It consumes the previous LC2 result, previous/revised LC1 results, typed diagnostic, unchanged purpose/tasks and a new output directory. It deterministically recompiles the revised exact source rows through the native builder, reassembles saved per-pair cards, and updates affected species in the immutable pre-deduplication card using its existing reference offsets. Unrelated card rows and decisions are preserved. Changed-content groups and dependent phase-family peers are reviewed through the existing LC2_3 workers using the previously accepted instructions; formerly dedup-excluded candidates remain eligible from the original baseline. Affected direct overrides are invalidated. Source/scope exclusions from the original input remain in force.

The bridge refuses implicit changes to component/reference basis, selected chemical coverage, auxiliary protonation/hydrolysis reference selections, estimated-source overlays or removed species. These return `needs_broader_review` for explicit review rather than silently patching dependent energies. Auxiliary source changes require dependent-pair closure beyond a local metal/ligand patch. A source defect is never resolved by discarding the chemical system or inventing an anchor.

Every accepted local revision records the exact source compilation receipt, before/after scientific rows, retained and invalidated decisions, targeted worker context index and full LC2_4 parser result. The result replaces both its per-pair reference paths and pre-deduplication baseline so a later repair cannot use the stale original card. Existing directories are not overwritten. The parent source-repair controller supplies the shared retry bound (default two attempts).


Card identity follows native source-qualified labels, with phase retained in each delta key. Canonical `species_id` is descriptive metadata, not a unique row key: oxide and hydroxide phase alternatives may share it. Repeated `(label, source)` identities are refused because the native inclusion editor cannot address them separately, even across phases. Source bindings are validated before the instruction supervisor or dedup workers are called.
