# `sweep_pipelines/_output_and_plotting/freeform_output/`

Reserved namespace for freeform-sweep output helpers. Currently
empty — freeform sweeps emit their wide CSV and topology JSON
directly from `freeform_sweep/freeform_sweep_export.py`.

When freeform-specific plots are added (e.g. faceted topology views
over a user-named axis), they will land here.
